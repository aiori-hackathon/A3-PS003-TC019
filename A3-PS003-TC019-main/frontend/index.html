THE IDEA BEHIND THE PROJECT

About Traffix.

Building a smarter perspective on traffic intelligence.

OUR VISION

Understanding traffic through intelligent vision.

Traffix is a research prototype exploring image-based vehicle detection and counting alongside federated learning. The project investigates how distributed clients can collaboratively train a global model while sharing model updates rather than pooling all training images centrally.

01 / DETECTION

Computer vision

Identify and count supported vehicle categories in traffic images using YOLO26n object detection.

02 / COLLABORATION

Federated learning

Explore local model training and central aggregation through the FedAvg approach.
